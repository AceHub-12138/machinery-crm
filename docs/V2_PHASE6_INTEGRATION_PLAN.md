# DachuanPro CRM/ERP V2.0 阶段 6 总集成收尾计划

## 本次范围

基线为 `codex/dachuanpro-v2.0-integration` 的 `42f9515`（已含阶段 5 入库作废）。本阶段为纯前端小闭环：

1. 入库单历史列表的状态筛选初始值改为“已确认”（`CONFIRMED`），首屏只显示有效入库单。
2. 保留“已作废”和“全部状态”筛选项，用户可主动切换查看历史。
3. 删除已作废列表卡片中的“反向审计号”展示；保留作废时间、作废人、作废原因。
4. 详情弹窗中的“作废反向冲减明细”和“操作日志”保持不变，保证审计追溯。

不修改 API/route、Prisma schema、migration、权限（`erp-roles`/middleware/permissions）、Agent/MCP 或 `VERSION`；不执行任何数据库操作。

## 风险评估

- 数据库风险：无。本次不修改 schema、migration、API 或数据。
- 权限与审计风险：低。权限和接口契约不变；仅减少列表中的内部审计号展示，详情审计数据保留。
- 前端行为风险：低。默认请求将携带既有的 `status=CONFIRMED` 契约；用户仍可用既有选项查看作废单及全部状态。
- 回归风险：低。通过既有筛选/作废查询契约测试、全量测试、类型检查和生产构建控制。

## 回滚方式

本阶段无数据库、配置、上传文件或部署改动。若复核或上线前发现问题，直接将施工分支回退到基线提交 `42f9515`，或在集成分支还原本提交即可；恢复后入库列表将回到原“全部状态”初始显示和原列表审计号文本。
