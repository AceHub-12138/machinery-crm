## 开始之前

1. 如果已收到“环境已开好”，直接开始第 3 步。需要重新启动时，本机需有 Node.js 22 或更高版本。先打开 Docker Desktop，等它显示引擎已运行。打开本页同目录的 [acceptance-env 文件夹](acceptance-env/)，在资源管理器双击 **start.cmd**，它会运行 start-acceptance.ps1 并保留窗口。首次构建需要下载软件依赖，请等待出现“已就绪”的地址。
2. Windows 有时会用记事本打开 .ps1。也可以在该文件夹空白处右键“在终端中打开”，运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-acceptance.ps1`。执行策略仅对这次 PowerShell 进程生效。验收期间保持 Docker Desktop 运行。
3. 按 **Win + R**，粘贴 `%TEMP%\crm-acceptance\accounts.txt`，回车。每行依次为角色、登录邮箱和密码。第 1 行超管、第 2 行北区销售、第 3 行南区销售、第 4 行外贸。只在本机登录框粘贴密码。
4. 按表格顺序操作。更换角色时先退出当前账号，再登录指定账号。需要记下客户链接或附件链接时，复制浏览器地址到自己的临时记事本里。每行写下看到的现象，并填“通过”或“不通过”。采用、驳回、入池会改变样本，每轮只做一次。需重做时先保存验收记录，再停止并重新启动环境。
5. 在启动当日完成额度验收（以北京时间计日）。若跨过北京时间午夜，重新启动干净环境后再做。
