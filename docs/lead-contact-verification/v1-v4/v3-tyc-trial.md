# V3：天眼查小规模联调方案

状态：**暂缓（未充值）**。本轮没有充值、读取真实 Token 或调用真实供应商。

## 执行前置条件

1. 管理员完成充值，并在供应商后台确认账号、接口授权、Token、剩余额度、单次费用及计费口径。只在安全配置界面填写，不向日志或报告复制 Token。
2. 仅在隔离测试环境执行，确认数据库、上传目录和账号均为测试资源；禁止使用正式客户。
3. 本次真实请求硬性上限不超过 5 次；`LEAD_TYC_DAILY_LIMIT` 不超过 5，并扣除同日已用次数。供应商失败是否计费先查明，不用重试试探计费。
4. 停用模拟开关；检查额度能跨服务重启保留。由管理员确认本方案后另行授权执行，本轮仅交付方案。

## 样本与步骤

选择 3–5 家公开企业，每个样本优先只请求一次；企业名及预期由管理员预先核对，不保证所有返回形态都能被公开样本触发。

| 样本 | 预期核对 |
| --- | --- |
| 全称精确匹配、存续且有电话 | 保留查询名、匹配名、信用代码及来源；回填电话并按既有规则分配 |
| 返回不同企业 | 进入待人工确认；对照展示，禁止直接回填 |
| 无名称或无电话 | 无名称不可采用，只能驳回；仅邮箱不能视为有电话 |
| 注销企业 | 不采用、不分配；核对不可采用提示 |

每次调用前后核对本地额度、核验记录 charged 和供应商后台计费变化；记录请求时间、脱敏样本标识、结果类别及费用，禁止记录 Token、完整原始响应及完整电话号码。

在允许缓存的同一查询上再次请求，确认命中缓存且不增加本地额度；同时核对供应商后台没有新增计费。重启测试服务后再次读取额度，确认没有归零。缓存验证仍计入总请求流程记录；如意外未命中，立即停止，不能突破最多 5 次的供应商请求上限。

## 停止条件与恢复

出现 401/403、余额或额度异常、计费与预期不符、身份误配、越权或回填错误，立即停止后续及批量请求，保存脱敏结果并汇报。撤销本次测试配置、停止测试服务；不删除正式数据、不自动纠正业务数据、不回灌全库。
