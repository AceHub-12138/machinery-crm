日志轮转的参数属于模块，不能写成 app 的 max_size/retain：

```bash
pm2 install pm2-logrotate
pm2 set pm2-logrotate:max_size 20M
pm2 set pm2-logrotate:retain 7
pm2 set pm2-logrotate:compress true
pm2 startup
# 按实际服务账号审核并执行 startup 输出的系统命令，然后保存进程列表。
pm2 save
```

pm2-logrotate 和 startup 是服务器级设置，仓库新增配置不代表服务器已启用。参考：https://pm2.keymetrics.io/docs/usage/log-management/ 。
